THREE-EMAIL STUDY

Extract this whole ZIP and host the folder containing index.html on your server.
For local testing: python -m http.server 8000
Then open http://localhost:8000/email-01.html (or email-02.html / email-03.html)
Use HTTP/HTTPS and enable browser storage so choices persist across pages.

Open each email directly using its assigned page address:
email-01.html
email-02.html
email-03.html

There is no Email 1 / Email 2 / Email 3 navigation or inbox message list.
Use your eye-tracking software or externally supplied links to open each page.
index.html shows neutral instructions; it has no links to individual emails.
Only the selected email appears in the reading pane. The same layout is used
for all three pages. No images or external libraries are required.

Keep, Delete, Report phishing, and Report junk save one current choice per email.
Selecting another action replaces that email's prior category. Choices persist
within the same browser profile and site origin. Undo/Restore clears a choice.
Reset reports clears all four categories for all three emails. It keeps the
current page open. Reset before each participant.

Use the unique page addresses with your eye-tracking software. This website
does not itself record gaze data or send choices to a server. Choices are stored
locally in the browser; no export or research database is included.

Remove INSTRUCTOR-KEY.txt and this README from the participant-facing server.
The prior seven message pages have been removed from this package. When updating
an existing server, remove its old email-04.html through email-10.html files.
